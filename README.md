## Quadrix

Quadrix is an onchain asset-management platform built as its own stack. On Quadrix-built
contracts, fees and withdrawals are enforced by the code that holds the assets.

[quadrix.finance](https://quadrix.finance) · [How Quadrix works](https://quadrix.finance/docs)

Own capital only; no third-party deposits are open. Testnet contracts are unaudited demos.

### Repositories

- [quadrix-track-record](https://github.com/sungkuuu/quadrix-track-record) — the daily operating
  record of the Quadrix vaults: hash-chained, each day's head hash anchored on GIWA Sepolia
  (a testnet), with its verifier.
- [erc4626-design-gates](https://github.com/sungkuuu/erc4626-design-gates) — pre-audit design
  gates for ERC-4626 vaults: 26 decisions, 5 invariants, and the lemmas and test patterns behind them.
